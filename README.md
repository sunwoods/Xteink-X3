# Xteink-X3
收集关于阅星瞳X3的软硬件信息

阅星瞳官网： [www.xteink.com](https://www.xteink.com/)  
crosspoint官网： [crosspointreader.com](https://crosspointreader.com/)

***

拆开后的样子  
<img src="https://github.com/sunwoods/Xteink-X3/blob/main/readme-img/01.jpg" width="400"/>

主要器件  
*  ESP32-C3
*  PUYA 128Mbit Flash
*  QMI8658 姿态传感器
*  DS系列RTC时钟芯片
*  类似TP4056的电池管理芯片
*  TI BQ27220库仑计
*  ***ISO/IEC 14443a NFC Tag
